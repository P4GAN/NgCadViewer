# ng-cad-viewer

An Angular component for viewing STEP, IGES, BREP and PLY files in the browser, using OpenCascade (via
[occt-import-js](https://github.com/kovacsv/occt-import-js)) and three.js.

See the [repository README](https://github.com/P4GAN/NgCadViewer#readme) for setup, the API and a
[live demo](https://p4gan.github.io/NgCadViewer/).

## Building

```bash
ng build NgCadViewer
```

The build output is written to `dist/ng-cad-viewer`.
